# CircuLab: Biblioteca de las Cosas en la UAB
**Grupo:** 5  
**Enfoque:** UAB (Campus UAB)  
**Tema:** Residuos / Economía Circular / Consumo Colaborativo  

## 1. Objetivos y Finalidades del Proyecto
El objetivo principal de **CircuLab** es reducir el consumo innecesario y la generación de residuos en el Campus de la UAB mediante la creación de una "Biblioteca de las Cosas". Se trata de un servicio de préstamo de objetos de uso esporádico (herramientas, material electrónico, material de acampada, juegos, etc.) para la comunidad universitaria (estudiantes, PDI y PAS).

Las finalidades específicas son:
* Fomentar la economía circular y la reutilización dentro del campus.
* Reducir la huella ecológica y el gasto económico de los estudiantes.
* Crear una plataforma digital centralizada (web/app) para gestionar el catálogo y las reservas de forma sencilla.

## 2. Criterios Mínimos de Éxito
Para considerar el proyecto exitoso en su fase final, se establecen los siguientes entregables mínimos:
* **Plataforma Web/App funcional:** Donde los usuarios puedan registrarse con su correo UAB, ver el catálogo de objetos disponibles, comprobar la disponibilidad y realizar reservas.
* **Prototipo físico / Sistema de gestión:** Un modelo operativo o piloto de cómo funcionaría el punto físico de recogida y devolución en el campus (incluyendo el sistema de inventario y control de estado de los objetos).
* **Documentación técnica y de usuario:** Manuales de uso y despliegue del proyecto en GitHub.

## 3. Gestión de Roles del Equipo
Para asegurar una correcta organización, las responsabilidades se dividen de la siguiente manera:
* **Integrante 1** - *Gestión de Proyecto y Diseño (UX/UI):* Encargado del tablero Kanban, diagramas de Gantt y diseño de la interfaz de usuario de la plataforma.
* **Integrante 2** - *Desarrollo Front-end:* Implementación de las vistas de la página web y conexión con el sistema de catálogo.
* **Integrante 3** - *Desarrollo Back-end y Base de Datos:* Creación de la lógica del servidor, gestión de usuarios UAB y sistema de reservas.
